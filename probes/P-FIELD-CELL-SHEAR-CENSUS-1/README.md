# Five fixed field-cell shear types

PUBLIC / NON-CANONICAL / L1 candidate. Author lane C of
[#1548](https://github.com/mathorn1973/twist-j/issues/1548), claimed in
[#1554](https://github.com/mathorn1973/twist-j/issues/1554).

This package compares five specified unweighted CW-cell incidences and their
orientation markings. It distinguishes inherited canonical shear results
from the bounded comparison, including an explicit infinite-order certificate.
It neither selects five physically nor classifies all field cells.

- PREREG.md freezes the domain, targets, failure threshold and execution rules.
- SOURCES.json binds admitted canonical inputs to exact v102 bytes.
- PROOF.md gives the analytical argument; LINEAGE.md states inherited scope.
- verify.py audits exact coefficient identities and all 248 specified
  orientation markings after its immutable public pin.
- The actual first run and disposition belong in EXPECTED.txt, RUN.md and
  RESULT.md, once execution has occurred.

Independent RC reviewers must respect the pre-pin exposure contract in
PREREG.md: only that specification, SOURCES.json and admitted canonical inputs
are allowed before their own derivation and freeze. A same-session helper
review is part of author preparation, not independent scientific review.
