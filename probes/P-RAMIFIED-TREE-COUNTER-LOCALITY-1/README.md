# Intrinsic ramified addresses and the cost of transport

Author: A. M. Thorn <thorn@twistj.com>. Apache-2.0.

Formal probe `P-RAMIFIED-TREE-COUNTER-LOCALITY-1`, owner issue
[#1296](https://github.com/mathorn1973/twist-j/issues/1296).
L1, proof-first, result-exposed. This directory does not change Public Canon v94.

The powers of the unique prime above five define a rooted tree intrinsically.
The natural integer counter visits a precisely counted subset at each depth,
while the affine group generated by translation by one and multiplication by
J can reach every address. Neither fact implements physical transport.

Literal simultaneous transport of independent cell data has two different
necessary costs: graph distance gives a depth-dependent latency; a fixed
finite cell alphabet additionally gives an exponential communication-capacity
bound through the root cut. Both statements freeze the carrier and encoding.
They are not impossibility theorems for all native readings or all geometries.

- `PREREG.md`: frozen equations, audit range, failure routes and authority.
- `PROOF.md`: universal written proofs and scope boundaries.
- `verify.py`: standard-library exact finite audit, pinned before execution.
- `EXPECTED.txt`, `RUN.md`, `RESULT.md`: added only after the public pin runs.
- `REVIEW.md`: explicit independent reasoning/static reviews and limitations.

Run from the repository root:

```sh
python3 probes/P-RAMIFIED-TREE-COUNTER-LOCALITY-1/verify.py
```

The all-depth theorems rest on the proof, not extrapolation of the finite
audit. A later separate reviewed fold is required for canonical registration.
