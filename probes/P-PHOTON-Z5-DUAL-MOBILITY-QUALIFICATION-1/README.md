# P-PHOTON-Z5-DUAL-MOBILITY-QUALIFICATION-1

Formal zero-evidence L3/L4 mobility qualification for the exact hard dual
target reserved on issue #756.

The package tests whether one fixed sector-umbrella wrapper, retaining the
immutable #767 transition with positive probability, moves both the integer
current and all six `H_2(T^4;Z_5)` coordinates while preserving the original
bottom marginal.  It contains no Ward statistic and cannot satisfy F3.

Permitted pre-pin fixture:

```sh
python3 probes/P-PHOTON-Z5-DUAL-MOBILITY-QUALIFICATION-1/qualification_run.py --fixture
```

After the immutable branch pin is pushed and publicly read back, the one
formal command is the exact explicit invocation in `PREREG.md`.  Its
formal-only preflight requires `git`, `gh`, the exact ten-line issue receipt,
all pinned bytes and unclaimed local and public attempt refs.  Both refs are
consumed before compilation or data.  Complete stdout becomes `EXPECTED.txt`.
Public replay uses only read-only `git` network access and:

```sh
python3 probes/P-PHOTON-Z5-DUAL-MOBILITY-QUALIFICATION-1/verify.py
```

Replay is enabled only after a clean, committed result child adds exactly
`EXPECTED.txt`, `RUN.md` and `RESULT.md`; untracked result-shaped files are
rejected before any chain is regenerated.  It also requires the immutable
public attempt ref at the pin and the public qualification branch at that
result commit.

Possible completed terminals are

```text
DUAL_MOBILITY_QUALIFICATION_PASS
STOP_MOBILITY_QUALITY
STOP_MOBILITY_INTEGRITY
```

Every terminal is `ZERO_ENGINEERING_ONLY`.  Production issue #742 remains
forbidden, and a PASS still requires the separate public wrapper-versus-new-
freeze governance decision before any F3-capable successor may be reserved.
