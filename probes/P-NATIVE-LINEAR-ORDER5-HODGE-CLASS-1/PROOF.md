# Proof/audit: no native linear word has the Hodge order-five type

**L1 exact finite classification.**

Let Gamma_lin be the frozen group generated by the five native linear parts.
Because every generator is an involution, breadth-first closure under right
multiplication is already group closure. The verifier exhausts the frontier,
then checks inverse membership and every generator edge for every element.

The resulting group has exactly

    |Gamma_lin| = 200.

Among these, exactly 24 nonidentity elements satisfy g^5=I. Since 5 is prime,
these are exactly the order-five elements.

For an order-five matrix over F_5, X^5-1=(X-1)^5. Hence the matrix is
unipotent and its GL_6(F_5) similarity class is determined by the Jordan block
partition, equivalently by the ranks of (g-I)^k for k=1,...,5.

Every one of the 24 native order-five elements has the same rank sequence

    1,0,0,0,0,

hence Jordan type J_2(1)+J_1(1)^4. The shortest BFS witness is the canonical
word bc. Thus the full native linear group does not contain a deeper
order-five unipotent chain than the canonical control.

For the marked Hodge five-cycle A_h=Lambda^2 C_4, the exact rank sequence is

    4,3,2,1,0,

which is Jordan type J_5(1)+J_1(1). No native order-five element has this
similarity invariant. Therefore no finite native word has a linear part
GL_6(F_5)-conjugate to the marked Hodge five-cycle or its inverse.

The fired linear subgroup generated by b,d,e has order four and contains no
order-five element, agreeing with the existing fired-commutator boundary.

This is a complete finite theorem for the frozen native LINEAR WORD class.
It does not classify affine conjugacy classes with independent target
translations, time-dependent gauges, histories, nonlinear readings or
counter-dependent cocycles.
