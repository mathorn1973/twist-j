# Five-point preparation and sharp endpoint readout

L1 proof for P-U-POINT-SOURCE-READOUT-DICHOTOMY-1. No Canon status is created
by this probe. A. M. Thorn; original text Apache-2.0.

## Exact class

Let five distinct native preparations x_s, s=0,...,4, share a clock phase.
Every finite deterministic native protocol gives one complete endpoint f(s).
The placement, start phase and duration are arbitrary. An enlarged output
label can contain deterministically specified finite history, without
asserting that the history was physically written.

Let E=Q5 with its counting form, H=ker(sum), Pi=I5-ones5/5, and
N_f e_s=e_f(s) in the counting-form output space. Real or complex scalar
extension is explicit when using general real response weights. This FREE
representation is chosen; arbitrary noninjective N_f is not assumed to be
a normalized quantum channel. The endpoint reader is exactly a diagonal
positive contraction D, with complementary outcome I-D. A non-diagonal
coherent measurement is outside this classical reading class.

## Collision/retention dichotomy

If f(s)=f(t) for s!=t, then d=e_s-e_t lies in H, has squared norm two,
and N_f d=0. Thus N_f cannot preserve the full Gram on H. Any subsequent
linear branch map also annihilates d, so such processing cannot restore a
complete instrument on all H. This is loss of a nonzero contrast, not a
normalization convention.

Conversely, if f is injective, the five image basis vectors are orthonormal.
Then N_f is an isometry on all E and hence on H. This proves the equivalence
for every point map, and therefore for every finite deterministic native
protocol at the stated preparation scope.

In the injective case N_f^*D N_f=diag(w), where w_s=D_(f(s),f(s)) lies in
[0,1]. Compression gives F(w)=Pi diag(w) Pi restricted to H. Conversely,
any w in [0,1]^5 is obtained by assigning those responses to the five
distinct output coordinates. This is the entire endpoint-reader class.

## Compression lemma and sharpness

For a finite-dimensional isometry V into a counting-form space, put
P_C=VV^*, D a diagonal positive contraction, and F=V^*DV. Expansion gives

    F-F^2=V^*D(I-D)V + V^*D(I-P_C)DV.

Both terms are positive semidefinite. For binary D the first vanishes,
and the second is the Gram of (I-P_C)DV. Thus F is a projector iff D
preserves ran(V). Since D is self-adjoint, this also preserves the
orthogonal complement, equivalently [D,P_C]=0. This is a standard lemma
used in this proof, not a separate Canon claim.

For the simplex take V to be the inclusion H->E, so P_C=Pi. If F(w) is
sharp, both positive terms must vanish. The first forces every
w_s(1-w_s)=0: for each s, the vector e_s-e_t in H has a nonzero s
coordinate, so a strictly positive diagonal term could not vanish on all
H. Therefore all entries are binary. The second term forces DH subset H.
But the coordinate sum of D(e_s-e_t) is w_s-w_t; it follows that every
w_s is the same. The only possibilities are all zero and all one, yielding
0 and I_H. Both indeed are sharp. This proves the full continuous theorem
without extrapolation from finite response tests.

For a binary mask selecting k coordinates, its defect has trace
k(5-k)/25. To see this, the two subspaces of contrasts supported within
the selected and unselected coordinates have eigenvalues 1 and 0. For
0<k<5 the remaining line is generated by Pi 1_S and has eigenvalue
(5-k)/5, so its defect is k(5-k)/25>0. At k=0,5 the defect is zero.

## QDD target and boundary

Write u_s=Pi e_s and Bv=sum_(i=1)^4 v_i u_i. Then B^*B=G=I4-ones4/5,
and B is an isomorphism onto H. The coordinate projector ones4/4 is
carried to (5/4)u_0u_0^*, since sum_(i=1)^4 u_i=-u_0. Its complement is
the three-dimensional HIGH projector. Both are nontrivial and therefore
excluded by the theorem in the five-point/free-encoding/classical-reader
class. This uses the algebraic targets without adopting physical effects.

The finite audit's 52 partitions represent every point map up to relabeling
its at most five occupied output coordinates. Each noninjective partition
has an explicit killed contrast. The compression-identity coefficient
checks are polynomial identities; the proof supplies their positivity
consequence on the complete continuous response domain. The disconnected
control confirms that the lemma admits sharp effects when the code permits
them, rather than imposing a blanket prohibition on diagonal readers.

The theorem excludes neither other coherent amplitude encodings nor
non-diagonal coherent output operations. In particular the sixteen-state
Galois-fiber code is a different correlated encoding, compatible with this
five-point obstruction. No complete admissible physical apparatus class is
declared empty. Physical preparation/adoption, actual event, occurrence,
material record/reset, apparatus selection and physical layer gates are
separate unresolved obligations.
