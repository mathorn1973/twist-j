# First native step with physically encoded retained memory

**NON-CANONICAL conditional ideal-model candidate.** Reservation
[#1368](https://github.com/mathorn1973/twist-j/issues/1368).
Public authority remains Canon v97. See [PREREG.md](PREREG.md) for the
prospective contract; no result is implied by this pre-run document.

The task after #1367 is to cross the cut between the fourteen prescribed
data registers and an explicitly counted memory. This candidate uses two
additional Ca40 five-level ions and a counted finite counter ion. The
dictionary is fixed from preparation. For the actual 25 inputs after the
first contact, a common finite program computes all first-step data outputs
while retaining M1=s, M2=1 and advancing N=0 to N=1. The s=3 and s=4 data
outputs may then agree while the full physical outputs remain orthogonal.

The interaction extension is explicit: a global state-dependent LS force
on all seventeen ions plus individually addressed, phase-controlled 729nm
star rotations. It does not assume an isolated LS beam for each requested
pair. A finite 500-loop affine refocusing word cancels every spectator
dependence to a scalar and isolates an equality phase on the selected
memory/data pair. Compiled rotations then transfer the present q label to
memory and prepare the required receiver coordinates under that physical
memory's control. No abstract controlled gate or SWAP is supplied for free.

The analytical construction has 156000 global LS loops and a conservative
bound below 19.1 million elementary carrier pulses. It is an intentionally
unoptimized finite witness. Its practical device error is not established;
the source experiments' short-gate fidelities cannot be transferred to it.

The local input is the supplied post-contact family with memory prepared
and counted from the start. This does not certify preparation, the previous
contact's embedding, a general native step, reuse of occupied memory,
the full history to n=9 or its physical error. Motion may return while
memory retains the history. A finite quantum controller/work-source account
remains distinct from the prescribed-field ideal model.

The earlier local contact construction #1365, the restricted data-only
obstruction #1367 and the physical HOLD keep their original scope.
