# D3 differential static work under independent clocks

Use the same v113 flat scalar D3 operator A and the same grounded-box solver as shell.py. The operator retains all weighted displacements of squared lengths 2, 4, 8, 10, and 16 with scale 1/324. The time rule is the scalar v113 recurrence with external additive source. This probe reads work from a static scalar potential and independently measures the switched-source timing of that law.

On grounded cubes of half-width 10 and 11 solve the unit monopole equation A*G = delta_origin. Retain every weighted edge leaving the interior and set the exterior potential to zero. Substitute at every site and check the net exterior sink. For each displaced point x read the signed unit-source work W = G(x)-G(2*x), where the fixed work order is inward potential minus outward potential. The source controls -1, +2, and zero follow from exact linearity of the same grounded system: their W reads are -W, 2*W, and zero. Both grounded geometries use the same work endpoints.

Use axis points (2,0,0), (4,0,0), and face-diagonal points (1,1,0), (2,2,0), (3,3,0). Add three equal-radius comparisons between distinct cubic orbits: (3,3,0) and (4,1,1) at r^2=18, (5,1,0) and (4,3,1) at r^2=26, (5,5,0) and (5,4,3) at r^2=50. All doubled endpoints are interior in both grounded cubes. Record both potentials, work, each first receipt, and the exact work difference between box sizes. This reports finite-volume sensitivity at fixed physical endpoints. The selected radii are finite samples, and the larger coordinate doubles approach the wall of the smaller cube.

The low-k stiffness gives squared tangent speed one. The tangent clock convention assigns T_tan=2*r with r=|x|. Record the signed action T_tan*W as rational coefficient 2*W multiplying sqrt(r^2), and also its rational square. At an unbounded asymptotic monopole G(r) ~ 1/(2*pi*r), this comparison would approach 1/(2*pi) for a unit source, with direction-dependent corrections. The finite results do not presume an error tolerance against that continuum reference.

For the causal clock, set the initial switched-source states psi_0=psi_1=0, and for t>=1 apply psi_(t+1)=(2I-A)*psi_t-psi_(t-1)+delta_origin. Use the same grounded domain and solve in exact integers by scaling psi_t by 324^(t-2). Find the first nonzero response at every endpoint by tick 12 and record its exact amplitude. Independently require agreement with the minimum stencil-hop count d and weighted shortest paths, whose positive products give the first nonzero amplitude at tick 2+d. The factor 324 in each transition is included. First arrival at the origin is tick 2. The causal clock convention uses T_caus=first_tick(2*x)-2, measuring elapsed time from origin activation to the outer receipt. Record T_caus*W and the squared ratio T_caus^2/T_tan^2. No work result selects or fits a clock.

These products are disclosed unit-action comparisons based on externally imposed static work. The tangent and causal clocks sample different features of the same discrete evolution. A disagreement between clocks does not invalidate the dispersion or first-arrival measurements. Neither comparator identifies the externally imposed D3 source with an H3 charge code, specifies an H3 native detector action, or establishes an equality of independently measured coupling constants.
