# Independent two-contact counterimplementation plan

This plan and the accompanying independent code are frozen before reading the new construction primary.py or any other new primary implementation. The contract, public #1353 claim, the coordinator's serialization specification and prior disclosed #987/native results are known. The new construction PROOF.md is not yet read. This is disclosed independent implementation, not blind discovery. There has been no scientific execution for this stage.

The reviewed contract is construction/CONTRACT.md, with its hash recorded in REVIEW-FREEZE.json. The domain is two six-pentit receivers, two source pentits and one common nonnegative counter. Both receivers are initialized at rho=(0,0,0,0,1,0). Sources a_i+1 are independent. A generic scalar/trace exchange occurs only at n=0 on S1:R1 and n=6 on S2:R2, before both receivers take an actual native step; source ports otherwise remain static. The output reader is the inherited fixed W=(p1+p1p)^2. No source label feeds the transition or reader after preparation. No receiver is held or reset.

The independent implementation constructs all five native generators as explicit homogeneous 7x7 matrices. The exchange is a transposition in the independent (s,z,P,r) chart; converting back uses q=z-sum(P)-r. It never imports primary code or an earlier verifier. Every source/receiver pair in the 78125-point primitive domain is checked for involution, source/trace exchange and unchanged other coordinates. Full checkpoints and actual indices are retained through all 25 protocols and all ten boundaries. The same finite protocol is separately simulated with exchanges disabled as a predeclared negative control.

Every reached row is checked for canonical coordinates, source consumption, pointer targets and complete independence from the other source. The common second readiness state at n=6 is checked against (2,1,3,4,0,4), and complete-state collisions (0,0)/(1,0) are retained rather than suppressed. An exhaustive 6250-state X14 check for both controls audits the one-step A->-A identity and trace closure used by the written all-time retention induction. This finite audit does not by itself prove an unbounded-time theorem; the proof must provide the induction.

The fixed shared serialization is UTF-8 JSON without spaces plus LF. History rows are ordered a1,a2,n and contain [a1,a2,n,s1,s2,*R1,*R2]. Contact rows are ordered a1,a2 then n=0,6 and contain [a1,a2,n,source_before,source_after,*receiver_before,*receiver_after], describing the algebraic exchange before U. The shared result fields are status, input_pairs=25, history_rows=250, contact_rows=50, history_sha256 and contact_sha256. Independently counted audit assertions and negative-control hashes may be additional fields. Stdout uses explicit UTF-8/LF bytes. Optional evidence belongs only under TWISTJ_EVIDENCE_DIR/independent, with each artifact below 5 MiB. No file is written during ordinary no-argument replay unless that explicit evidence variable is supplied.

Before freeze, only source writing, AST parsing and byte hashing are permitted. After freeze, static primary-code/proof review may occur; any code correction requires a separately preserved version and truthful exposure chronology. Execution waits for the coordinator's public preregistration pin and release. Failed assertions, outputs and frozen bytes must be retained; no target, timing, reader or source-code repair may follow a scientific run under the same pin.
