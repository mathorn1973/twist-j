# Balanced signed native material current

Test the post-freeze analytic prediction from the secondary observation in [#2036](https://github.com/mathorn1973/twist-j/pull/2036) in a new preregistered coupled H3 block. Use the pinned native verifier on the same 16 by 8 torus with initial matching bit zero. Use fixed directed reads from row 0 to row 1 and row 4 to row 5 in column 2.

Set L = 1 - rho and A = 1 - 2*rho. In the first row band (7,0,1,2) load antipodal matter gaps (a,a,L,L), where a = -p*J^2 and p = +/-1. In the second band (3,4,5,6) use the same pattern with a = p*A. The target radiation starts at zero. Each band has a primary source tile starting at column 0 in incident arms or 12 in distant arms, and a complementary tile starting at column 6. Their rows are (0,1) for the first band and (4,5) for the second. The four cells of a tile have (d,-d,4,-4). Let d = 4*u at primary code q = -1 and d = 4/u at q = +1, where u = j + 1/j. The complementary tiles have the opposite code. All other sites start at zero.

The target's two phase codes have identical Hermitian values on each of their initial rails. That follows from the sign change on resident gaps, with the receiver gaps held fixed. The probe H is 56 + 4*phi and Q = 116. The full ledger is M = U = 0, H = 1336 + 4*phi, Q = 2676.

At 2C in the incident arms the two row bands receive CORR = -2*L*J^(-q) on each tile-aligned target row. No other coordinate in the target column changes through 2C. At 2B the two receivers have B1 for q = -1 and B2 for q = +1. Other target cells have B0. The distant arms keep zero incident CORR and all target cells have B0. At 3C the parity gate admits the first read edge for q = -1 and the second for q = +1 in the incident geometry. Here A has residue 1 modulo 2, so the second-band parity is unchanged relative to #2036. Its resident remains B0 because the rational norm of the field-to-matter gap norm ratio is 5/31.

In the first band the admitted outputs give oriented scalar flux +10 for p = -1 and -10 for p = +1, as in the prior measurement. In the second band the receiving gap before 3C is J^(-1)*L, with Q = 20. After 3C it is (1+p*A)*L/2. For p = -1 this is rho*L with Q = 10. For p = +1 it is L^2 with Q = 30. The second edge therefore gives -10 and +10. Unselected edges give zero. The four incident sum values are 10*q*p, exactly. The four distant arms give zero on both edges. Score each current as the change in receiver matter Q at C only. Require the partner's opposite change in full Hermitian H, the complete ledger on all cuts, and exact composed reversal back to the launch.

The target program p controls an internal phase relation and keeps the signed Hermitian preparation account fixed. The test measures a signed material current on fixed edges. It does not assign H3 preparation tags to the externally imposed source of the D3 static Poisson model.
