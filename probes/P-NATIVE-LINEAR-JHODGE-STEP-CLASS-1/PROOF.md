## 1. The actual reduced J-Hodge step

    M_h = I + C_4^2,
    L_h = Lambda^2 M_h.

The exact verifier constructs these matrices directly. It finds

    ord(L_h) = 10,

and, for N_h=L_h+I,

    rank(N_h^k) = 4,3,2,1,0,0     for k=1,...,6.

Thus L_h is (-1)-unipotent with Jordan type J_5(-1)+J_1(-1). The marked
cycle A_h=Lambda^2 C_4 has the corresponding +1-unipotent sequence
4,3,2,1,0,0. This equality is a control, not a premise of the decision.

## 2. Complete native linear word group

The verifier rebuilds the complete group Gamma_lin generated by the five
native linear parts, with no word-length cutoff. Exhaustion of the BFS
frontier, inverse membership and all generator edges certify

    |Gamma_lin| = 200.

A native element can be similar to L_h only if g+I is nilpotent. Exactly
25 native elements satisfy (g+I)^6=0. They split into two similarity types:

    ranks 0,0,0,0,0,0 : 1 element, namely -I (shortest word d);
    ranks 1,0,0,0,0,0 : 24 elements (shortest word bcd).

No native element has the target sequence 4,3,2,1,0,0.

For a matrix with unique eigenvalue -1 in characteristic five, the ranks of
successive powers of g+I determine the nilpotent Jordan partition. Therefore
none of the 200 native word linear parts is GL_6(F_5)-similar to L_h.
