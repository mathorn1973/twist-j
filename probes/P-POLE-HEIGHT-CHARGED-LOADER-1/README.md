# Searching for a fixed charged-reference loader for five unknown inputs

NON-CANONICAL / L1 prospective bounded construction search.
Reservation: https://github.com/mathorn1973/twist-j/issues/1895.

This probe asks for one fixed word of total integral contacts taking the
five preparations (B_t,-B_t,u,u,0,2), B_t=t(1-j^2), -2<=t<=2, to first four
slots (u+B_t,u-B_t,0,0), with u=1-j. All helper endpoints are accounted for.
They need not return to their initial phase; a returned catalyst is claimed
only if its complete final values actually agree with its preparation.

The extra blank beside the nonneutral reference is explicit. Uniformly
neutral preparations and a lone reference 2 have narrower obstructions.
The search is a finite deterministic heuristic, not a complete decision
procedure. A non-finding does not establish an impossibility theorem.

[PREREG.md](PREREG.md) fixes the inputs, search, budgets and acceptance
checks before execution. [PROOF.md](PROOF.md) gives the analytical
reductions, helper classification and scoped lower bounds.
[PROVENANCE.md](PROVENANCE.md) and [SOURCES.tsv](SOURCES.tsv) bind exposure
and public sources. The accepted [verify.py](verify.py) searches and audits
any found word with elementary contacts and complete inverse recovery.

The native finite-field pistons and the O-slot input encoding are different
carriers until an interface is supplied. Loading this declared O-slot
family does not compile native U, identify arithmetic residues with
electric charge, select a physical action scale or derive alpha. The
supplied negative copy and reference cells are preparation resources.

If a word is found, a second accounting layer explicitly prices its
interaction-energy excursions. A separate loader bank and reader bank,
with a declared schedule selecting which bank pays, prevent the reader's
ten-unit stock from hiding the preparation cost. This is an accounted
schedule, not an autonomous switch or a persistent measurement record.
