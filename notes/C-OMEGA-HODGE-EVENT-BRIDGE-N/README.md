# Native Omega to Hodge-event address bridge

PUBLIC NON-CANONICAL. Owner #1243.
Author: A. M. Thorn <thorn@twistj.com>.

This candidate specializes the registered arbitrary-target native reader
classification to the selected Hodge event mesh.

Main result:

    B_G(n,x)=e_h(n,G(ell_n(x)))

is the complete reachable clock-aligned point-bridge class. A faithful
3125-worldline example is executable in bridge.py.

The result is deliberately two-sided. Exact event addressing exists, but the
native intertwining equation does not select the Hodge target, resolution or
spatial assignment. A point/bounded-batch reader also cannot generate an
entire unbounded spatial slice.

Read PREREG.md for frozen scope, PROOF.md for all-class arguments, RESULT.md
for the conclusion and RUN.md for the finite audit.
