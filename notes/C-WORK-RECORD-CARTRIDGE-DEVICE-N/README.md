# Three-cell work-to-record apparatus: capacitor-cartridge design

NON-CANONICAL / OPEN engineering proposal. Owner: issue #1317.
No apparatus has been built or qualified; no laboratory observations exist.
Public authority remains Public Canon v95.

This is one concrete implementation proposal for the unchanged mathematical
law of [#1316 at 312d0a90b24d5f9e743096f0ee2a477cda719a10](https://github.com/mathorn1973/twist-j/tree/312d0a90b24d5f9e743096f0ee2a477cda719a10/notes/C-FIELD-WORK-RECORD-UNIT-N).
Its candidate-T/L1 theorem already joins transmitted work to a retained local
record. That mathematical connection is not an outstanding task here.

The proposed bench apparatus combines a complete finite encoding of all 96
coordinates with eleven measured capacitor energy banks. Five insulated
resource cartridges physically exchange neighbouring docks. At the target,
the arriving cartridge supplies electrical work to a separate matter bank;
only the completed accepted reaction advances a local five-position wheel.

- [DESIGN.md](DESIGN.md): domain, encoding, actual energy path, fixed layers,
  reverse operation, component choices and all auxiliary resources.
- [TEST_PLAN.md](TEST_PLAN.md): numerical requirements, qualification before
  confirmation, cartridge-then-isolated-source hardware stages, four controls,
  holdout preparations, blind target assessment and rejection rules.
- [REVIEW.md](REVIEW.md): scope and engineering review disposition.

The numerical requirements are selected design targets, with derivations and
instrument constraints. They are not measured performance. In particular,
catalogue leakage and converter-efficiency specifications do not guarantee
this design will pass. Component qualification is the first go/no-go task.
Failure requires rejecting or revising the design before a new public pin;
it does not permit hidden charging or relaxed thresholds during confirmation.

This package is a reviewable system design, not fabrication files or an
execution-ready laboratory preregistration. Circuit/layout, fixture drawings,
firmware, calibration certificates and a separately owned physical gate must
be frozen before the confirmation campaign. Those deliverables and all actual
construction/measurement remain open. No verifier or simulation is supplied
as a substitute for the missing apparatus.

Dependencies remain #1316 -> #1312 -> #1310. #1314 uses another law and is
comparison only. This proposal changes none of those sources, no Canon file,
no registered owner, no memory capacity and no layer status. It does not
identify its capacitors with physical fields selected by J or claim that the
externally controlled apparatus is a closed autonomous physical universe.
