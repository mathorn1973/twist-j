# Hodge-Tate CM5: Perry equivariant audit and theta-symmetry breaker

**STATUS: NON-CANONICAL RESEARCH NOTE.**

**Basis:** Public Canon v83 and the companion Hodge-Tate / Markman CM5 notes through
`HODGE-TATE-CM5-MARKMAN-W2E-M1-SIMPLE-SHEAF-2026-09-11.md`.

**Date:** 2026-09-11.

This note opens the Perry-equivariant branch **W2E-A** for the scale-one CM5 secant class. It does not prove or disprove Perry's general equivariant semiregularity theorem in the CM5 setting. It audits the most natural implementation of that theorem for the explicit divisor-supported scale-one sheaf from W2E-B: finite theta/Rouquier symmetries generated by translations stabilizing the polarization divisor, with the corresponding compensating degree-zero tensor action.

The result is a clean negative statement for this particular implementation. A symmetry group large enough to make source `G`-semiregularity dimensionally possible must contain a full five-primary Lagrangian plane, but the codimension-three correction class `Q` does not descend integrally through **any** of the 156 such planes. Groups for which `Q` does descend have order at most 80, and their invariant obstruction space is already too large for the source semiregularity target.

No `canon/` file is changed, no public claim is registered, and no algebraicity theorem is claimed.

---

## 1. Perry's equivariant fork

Alexander Perry's 2026 semiregularity theorem extends the Buchweitz-Flenner mechanism to equivariant noncommutative varieties and twisted derived categories. The distinction needed here is:

- ordinary semiregularity asks for injectivity on all of `Ext^2(E,E)`;
- `H`-semiregularity only asks for injectivity on the invariant subspace `Ext^2(E,E)^H` for an object with an `H`-equivariant structure;
- weak `H`-semiregularity is formulated after passing to the invariant category and is weaker still.

Perry applies this to finite subgroups of the Rouquier group of an abelian variety, acting by translations and tensor products with degree-zero line bundles. His theorem is exactly the reason the enormous ordinary `Ext^2` spaces found in W2D do not end the programme.

Markman's earlier successful low-dimensional construction uses the same basic pattern: finite translation symmetries reduce the relevant obstruction space to an invariant part on which the semiregularity map can be injective.

The present note asks whether the explicit CM5 scale-one sheaf can be put into that pattern using its natural theta symmetry.

References:

- A. Perry, *The semiregularity theorem for equivariant noncommutative varieties*, arXiv:2604.00511, 2026.
- E. Markman, *Cycles on abelian 2n-folds of Weil type from secant sheaves on abelian n-folds*, arXiv:2502.03415, current 2026 version.
- E. Markman, *Secant sheaves on abelian n-folds with real multiplication and Weil classes on abelian 2n-folds with complex multiplication*, arXiv:2509.23079.

## 2. The scale-one source object

Keep

\[
X=B\times B,
\qquad
B=\operatorname{Jac}(y^2=x^5-1),
\]

and the rational secant class

\[
\delta=-\gamma,
\qquad
\gamma=v(j-j^{-1}).
\]

The preceding W2E-B note constructed a simple coherent sheaf

\[
G_1\in\operatorname{Coh}(X),
\qquad
\operatorname{ch}(G_1)=\delta,
\]

supported on a smooth divisor

\[
Y\in|L|,
\qquad
L=5D-E.
\]

It is obtained from

\[
F_0=i_*(\mathcal M|_Y),
\qquad
2c_1(\mathcal M)=L,
\]

by subtracting a curve sheaf with leading class

\[
Q=5D^3-DE^2=20AB(A+B).
\]

Ordinary semiregularity failed because the support moves in the 399-dimensional system `|L|`. The Perry route tries to kill most of those motions by finite symmetry.

## 3. Exact polarization type

Use the integral basis

\[
(1,j,j^2,j^3)
\]

of the CM5 lattice of one `B` factor. Multiplication by `sqrt(5)` is

\[
R=
\begin{pmatrix}
-1&2&0&-2\\
0&1&2&-2\\
-2&2&1&0\\
-2&0&2&-1
\end{pmatrix}.
\]

Put

\[
q=\frac{5+\sqrt5}{2},
\qquad
q'=\frac{5-\sqrt5}{2}.
\]

The multiplication matrices are

\[
M_q=\frac{5I+R}{2},
\qquad
M_{q'}=\frac{5I-R}{2}.
\]

Their Smith invariants are both

\[
\boxed{(1,1,5,5).}
\]

Thus on one abelian-surface factor the corresponding polarization has type `(1,5)`.

For

\[
\mathcal M=L/2,
\]

the two factors carry the conjugate polarizations `q'` and `q`. Hence

\[
\boxed{
\mathcal M\text{ has type }(1,1,5,5),
\qquad h^0(\mathcal M)=25.
}
\]

Doubling gives

\[
\boxed{
L\text{ has type }(2,2,10,10),
\qquad h^0(L)=400.
}
\]

Consequently

\[
|K(L)|=400^2=160000,
\]

and a maximal isotropic theta subgroup has order

\[
\boxed{400=16\cdot25.}
\]

This is large enough in principle to reduce the invariant obstruction space dramatically.

## 4. The five-primary theta kernel

Modulo 5, a kernel basis on one `B` factor is

\[
u_1=(1,3,1,0),
\qquad
u_2=(2,2,0,1).
\]

On `X=B x B`, use the four basis vectors obtained by placing `u_1,u_2` in either factor. In this basis the alternating theta pairing on `K(L)[5]` is

\[
J_5=
\begin{pmatrix}
0&3&0&0\\
2&0&0&0\\
0&0&0&2\\
0&0&3&0
\end{pmatrix}
\quad\text{over }\mathbf F_5.
\]

It is nondegenerate. Therefore the number of maximal isotropic planes is

\[
(5+1)(5^2+1)=\boxed{156}.
\]

Each such plane gives an order-25 five-primary isotropic translation subgroup.

## 5. Integral coordinates for the correction class

Let

\[
x_0,\ldots,x_7
\]

be the integral dual basis of `H^1(X,Z)` induced by the two CM5 bases. Exact exterior expansion gives

\[
\boxed{
\begin{aligned}
Q=40(&x_{012345}+x_{012356}+x_{012367}\\
&+x_{014567}+x_{124567}+x_{234567}),
\end{aligned}}
\]

where, for example,

\[
x_{012345}=x_0\wedge x_1\wedge x_2\wedge x_3\wedge x_4\wedge x_5.
\]

There is no floating point in this expansion.

For an isotropic subgroup `H_5` generated by residue vectors `h_1,h_2`, the quotient isogeny corresponds on homology to the overlattice

\[
\Lambda_{H_5}
=\Lambda+\mathbf Z\frac{h_1}{5}+\mathbf Z\frac{h_2}{5}.
\]

If an `H_5`-invariant integral curve class pulls back to `Q`, then `Q` must be integral on this overlattice. This gives an exact finite descent test.

## 6. Exhaustive five-primary descent test

All 156 Lagrangian planes were enumerated in reduced row-echelon form over `F_5`. For each plane, `Q` was evaluated on all six-fold wedges of the lattice generators

\[
e_0,\ldots,e_7,\frac{h_1}{5},\frac{h_2}{5}.
\]

The verdict is

\[
\boxed{
0\text{ of }156
\text{ five-primary Lagrangian planes admit integral descent of }Q.
}
\]

A small witness illustrates the obstruction. Take the Lagrangian plane with coordinates

\[
(0,1,0,0),
\qquad
(0,0,0,1)
\]

in the kernel basis above. In the integral eight-dimensional basis these lift to

\[
h_1=(2,2,0,1,0,0,0,0),
\]

\[
h_2=(0,0,0,0,2,2,0,1).
\]

Then

\[
\boxed{
Q\left(e_0,e_1,e_2,e_4,\frac{h_1}{5},\frac{h_2}{5}\right)
=-\frac{16}{5}.
}
\]

The full result is stronger than this witness: every one of the 156 planes has a denominator-5 breaker.

## 7. The obstruction is specifically five-primary

The two-primary part behaves differently.

Because `L=2M`, one has

\[
K(L)[2]\simeq\mathbf F_2^8.
\]

The induced alternating pairing is `M mod 2` and is nondegenerate. The number of maximal isotropic four-planes is

\[
\boxed{2295}.
\]

Exact enumeration gives

\[
\boxed{
85\text{ of }2295
\text{ two-primary Lagrangians admit integral descent of }Q.
}
\]

Every one-dimensional subspace of the four-dimensional five-primary symplectic space is isotropic, and their number is

\[
\frac{5^4-1}{5-1}=156.
\]

Thus the exact number of mixed subgroups with

\[
|H_2|=16,
\qquad
|H_5|=5,
\qquad
|H|=80,
\]

passing the cohomological descent test is

\[
\boxed{85\cdot156=13260.}
\]

So there are many genuine theta symmetries compatible with `Q`. The problem is not the existence of symmetry. The problem is that all compatible groups are too small for the semiregularity dimension bound below.

## 8. The invariant deformation lower bound

Let `H` be an isotropic translation subgroup of `K(L)` of order

\[
h=|H|,
\]

and use an honest theta linearization. In the present divisor-supported ansatz, choose the support section in an `H`-eigenspace.

The Heisenberg representation of the theta group restricts to `H` as copies of the regular representation. Hence each character eigenspace in

\[
H^0(X,L)
\]

has dimension

\[
\frac{400}{h}.
\]

Therefore support motion alone contributes at least

\[
\frac{400}{h}-1
\]

invariant first-order deformations.

There are also the standard translation/Picard directions in the identity component of the Rouquier group. For the simple scale-one object they give eight invariant first-order directions. Thus

\[
\boxed{
 e_1^H:=\dim\operatorname{Ext}^1(G_1,G_1)^H
 \ge 7+\frac{400}{h}.
}
\]

For a free nonzero translation, the equivariant Lefschetz contribution to the self-Euler characteristic vanishes. Averaging therefore gives

\[
\chi(G_1,G_1)^H=\frac{800}{h}.
\]

Simplicity and Serre duality give invariant dimensions

\[
e_0^H=e_4^H=1,
\qquad
e_3^H=e_1^H.
\]

Hence

\[
\boxed{
 e_2^H
 =\frac{800}{h}-2+2e_1^H
 \ge12+\frac{1600}{h}.
}
\]

On the source abelian fourfold

\[
\dim HH_{-2}(X)=28.
\]

Perry `H`-semiregularity of the source object therefore requires at minimum

\[
12+\frac{1600}{h}\le28,
\]

so

\[
\boxed{h\ge100.}
\]

This is the first load-bearing inequality of the audit.

---

## 9. The two requirements are incompatible

The two-primary isotropic part has order at most 16. Therefore any isotropic subgroup with

\[
h\ge100
\]

must have full five-primary order

\[
|H_5|=25.
\]

But Section 6 proves that no five-primary Lagrangian plane admits integral descent of the correction class `Q`.

Conversely, if the five-primary rank is at most one, then

\[
h\le16\cdot5=80.
\]

At the largest possible compatible size `h=80`, the invariant lower bound is still

\[
\boxed{
 e_2^H\ge12+\frac{1600}{80}=32>28.
}
\]

Thus the current theta implementation has no overlap window:

\[
\boxed{
\begin{array}{c}
Q\text{-descent}\Rightarrow h\le80,\\[2mm]
H\text{-semiregularity dimension}\Rightarrow h\ge100.
\end{array}}
\]

Therefore

\[
\boxed{
\text{the current scale-one divisor-supported secant ansatz cannot be made source-}H\text{-semiregular by an honest isotropic theta/Rouquier translation subgroup.}
}
\]

This is an exact finite/arithmetic breaker, not a genericity argument.

## 10. Why pure tensor symmetries do not enlarge this implementation

Perry's finite subgroups live naturally in

\[
X\times\widehat X,
\]

so one must also ask whether a large kernel in the translation projection could enlarge `H` using only degree-zero tensor symmetries.

For the present sheaf this does not help in the natural geometric implementation. Its codimension-one support is the smooth ample divisor `Y`. If

\[
G_1\otimes P\simeq G_1,
\qquad
P\in\operatorname{Pic}^0(X),
\]

then restricting to the rank-one locus on `Y` forces

\[
P|_Y\simeq\mathcal O_Y.
\]

For a smooth ample divisor in an abelian fourfold, restriction on `Pic^0` is injective. Hence

\[
P\simeq\mathcal O_X.
\]

So the stabilizer has no nontrivial pure-tensor kernel. In this ansatz the size relevant to the invariant-dimension estimate is genuinely controlled by the translation subgroup audited above.

---

## 11. Consequence for the Markman outer product

The intended Markman object is obtained from an outer product and an Orlov equivalence. The most direct Perry implementation would make each source secant sheaf `H`-semiregular and then transport the equivariance factorwise.

That route cannot work here. A nonzero invariant source obstruction lying in the kernel of the source semiregularity trace gives, after tensoring with the identity class on the second factor, a corresponding invariant obstruction direction for the outer product. Orlov equivalence preserves Ext groups and the relevant equivariant structure.

Thus the source failure above is already a breaker for the straightforward factorwise `H x H` strategy.

This statement is deliberately narrower than Perry's theorem. It does **not** rule out weak semiregularity of the outer object in a different invariant category.

---

## 12. What this does not rule out

The following remain open:

1. a different rational secant class in the four-dimensional space `B` whose correction term has better five-adic descent;
2. a different coherent realization of the same Chern character not built from the divisor-plus-curve exact sequence used in W2E-B;
3. a non-isotropic central extension or genuinely twisted equivariant structure;
4. direct weak `H`-semiregularity of the Markman object in Perry's invariant category, without source `H`-semiregularity;
5. a different finite Rouquier subgroup not captured by the honest theta-linearized translation implementation above.

So the verdict is a breaker for the **current implementation**, not for the Perry route as a whole.
