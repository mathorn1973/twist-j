  fibre partition given by equality of the three effective contact prices.
  There are five possible partition types. The minimum supplementary context
  alphabet on that fibre has as many values as there are distinct gains.

  necessary: one explicit Gauss-state fibre has gains 0, 40 and 25. This
  sharpens the earlier two-history 81/86 witness without changing its law.
* For a fixed known contact word, the final old state determines the entire
  gain archive by inversion. If arbitrary contact words are allowed and
  omitted, the exact archive fibres obey a stated recursion. Their minimum
  context size is not generally three. It is unbounded with history length,
  even on one fixed finite-energy shell and with a fixed initial old state.
* Two occupied, unbounded nonnegative-integer registers give one autonomous
  bijection that consumes contact choices and retains them without resetting
  either register. Fixed register count is not fixed information capacity.
