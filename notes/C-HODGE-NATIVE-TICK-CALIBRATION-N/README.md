# Hodge native tick calibration

PUBLIC NON-CANONICAL. Owner #1257.

This candidate calibrates the selected IDEAL Hodge event-time step to the registered dimensionless METRO tick T=2pi/5.

The calibrated metric on integer event labels is independent of event resolution h. Actual rounded integer events converge uniformly to that timing but are not exactly equitick at h=3.

Read RESULT.md for the conclusion, PROOF.md for the all-event bound and RUN.md for exact reproduction.
