## Scientific synthesis

A bank can conserve its exact positive trace account while losing the residue
inventory that enabled a preparation. The necessary resource is a prepared
state, not only a quantity of energy. In the supplied contact model:

| Proposed result | Exact scope |
| --- | --- |
| Integral reversible contact | Identity on refused pairs; sum, Hermitian norm, trace account and slot residues conserved |
| Sharp auxiliary minima 12 and 27 | Exactly 26 slots, four auxiliary slots, known input (6,0^21), signed or positive four-3 target, free whole-slot permutations |
| Retained-output bank boundary | No clean bank restoration with the output retained and all other resources restored |
| Many-output capacity | At least 4N changing auxiliary slots and trace account 12N; signed copies attain both; positive copies give only an upper bound 27N |
| Fixed common program boundary | Pairwise complete residue Hamming distance is preserved |
| Optional Gram/archive extension | Full integral Gram continuation and a separate seven-slot, fourteen-phase occupied archive with reading boundaries 6,7,8 |

The first five rows form the recommended narrow v107 core. The last row can be
accepted separately if its proof review passes. The 26-slot preparation and
seven-slot archive have different prepared families. Their conjunction into
one varied-input preparation, response, record and renewal apparatus is not
proved. Neither result establishes native-U implementation, measured energy,
event occurrence or a physical instrument.
