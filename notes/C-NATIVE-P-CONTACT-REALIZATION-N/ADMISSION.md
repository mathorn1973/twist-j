Tags classify what a source actually supplies. ADMITTED_CONDITIONAL means
an existing separately admitted resource within its precisely named
conditional architecture and premises, not independent physical admission
or automatic permission to use it as original U. A source formula alone
does not establish such separate admission.
NEW_DECLARED does not mean that a resource was first invented here: it
also marks source-apparatus resources newly supplied relative to original U.

## 4. Exact missing admission

The required certificate must name an already admitted native carrier
and complete dynamics, or establish a separately admitted extension,
then exhibit a fixed structural encoding of Y_(8,3) with all the fields
in CONTRACT sections 4-6. It must connect the actual source to actual
integer/Weyl data, fund every branch, provide the common fixed k and
inverse, preserve every auxiliary residue and spectator, and prove the
common-ready local receiver criterion.

No such certificate is present in the consumed sources. The present
work does not independently admit a replacement coupling, loader, control
program, arbitrary finite permutation or target-designed code.
Therefore the disposition is STOP_ADMISSION_UNSUPPLIED. This is a
statement about the supplied interface, not a complete classification of
all possible encodings or extensions.
