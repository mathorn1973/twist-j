## Scope firewall

- The result is relative to the one displayed `S,T` representative of
  `COLOR-INTEGRAL-LIFT`. It neither selects that representative nor
  contradicts `SPIN-LIFT-FORCED [F]`, which leaves four inequivalent
  marked lift classes.
- The historical identifier fragment `QCARRIER` means only the paired
  CM representation carrier in this note. It is not the decoder
  `QCarrier` type and does not define the public quadratic map `Q`.
- Exact `Q`, `QCarrier` equality, Gram/dagger/transpose data for the
  decoder, the common total domain, orbit-to-amplitude map, effects,
  Born pairing, `MatterData`, write map, and dependencies remain owned
  by `QUADRATIC-DECODER-DATA [O]` and issue #107. None is imported.
- No L5 stream, L6 measure, L4-to-L6 lift, U(1) dictionary, physical
  selection, or uniqueness of the public spin lift is asserted.
  `COLOR-MEASURE-SELECTION [O]` remains STOP and untouched.
- A marked Galois twist being isomorphic to the fixed representation is
  not called a descent datum. The nontrivial cocycle class obstructs an
  actual semilinear involution and a coherent arithmetic `C4` descent.
