## Exact statement

Freeze the natural compact hull of the public finite kernel:

```
Omega_hat = X_TM x F_5^6,   U_hat(kappa, psi) = (S_K kappa, F_{kappa_0}(psi))
F_eps(psi) = g_{z_6(psi) + 2 eps mod 5}(psi)                  canon section 8
X_TM        two-sided Thue-Morse subshift, shift S_K, unique
            substitution probability m_TM, reading theta(kappa) = kappa_0
Y_A = { (kappa, psi) : psi in A cap H_{kappa_{-1}} },  Y = union over 313
```

Then, on that frozen object:

```
S1  every U_hat-invariant probability measure projects to m_TM, distinct
    ergodic measures have mutually singular finite-fibre conditionals,
    hence M_e(U_hat) is finite
S2  every hull point satisfies psi in R cap H_{kappa_{-1}}: for every legal
    Thue-Morse word w of length 24 (all 76 of them) and of length 32 (all
    94), the image of all 15625 states under F_w is exactly R cap H_{w_last},
    of size 3125. Hence Y carries every invariant measure and no invariant
    measure lies outside the census living union
S3  the first-return words to symbol s at index -1 are exactly s, (1-s)s,
    (1-s)(1-s)s, because Thue-Morse contains no cube of a letter; the gap-2
    return map is the IDENTITY by the registered mirror law, so every return
    group is generated by exactly two involutions
S4  on all 626 pairs (A, s) the return group G_A^ret is dihedral of order
    10 with ord(gap3 o gap1) = 5, acting regularly on each size-20
    component half and transitively with order-2 stabiliser on each singlet
    half; every group element is realised by an actually occurring factor of
    the derived gap sequence, so reachability equals group orbits; and
    exhaustive search over every proper nonempty subset of every A_s finds
    no invariant subset
S5  U_hat has exactly 313 ergodic invariant measures, one per census
    component; the invariant-measure simplex is Delta^312; every vertex has
    entropy zero
S6  the algebraic hosting group H_1 = <d, b e b> of CENSUS-HOSTING [C]
    stabilises exactly one living half of each component and its
    b-conjugate b H_1 b stabilises the other, 313 halves each; on the half
    it stabilises, the hosting group restricted equals the dynamical return
    group. The naive form without the conjugation is FALSE on 313 of 626
    pairs and must not be folded
```

## Falsifier

```
1. a recomputation of the census under the frozen public protocol giving
   other than 313 components or other than |R| = 6250
2. a legal Thue-Morse first-return word to s at index -1 other than s,
   (1-s)s, (1-s)(1-s)s
3. a component A with U_hat(Y_A) != Y_A under the index -1 convention
4. an invariant measure nu with nu(Y_A) < 1 for every census component A
5. a second ergodic invariant measure on any single Y_A
6. an occurring factor of the derived gap sequence whose induced map on
   some A_s lies outside the reported order-10 group
7. for S6: a pair (A, s) stabilised by neither H_1 nor b H_1 b
```

## The one POLICY question the fold must answer first

Row 4 is a theorem only if an imported classical ergodic-theory theorem may
carry a public T. The finite content is fully public and exhaustive; the
last step is a citation. Three options:

```
a  fold row 4 at T with the imported theorem named in scope. Cleanest
   reading, but it makes a public T depend on literature the repository
   does not verify.
b  fold row 4 at D and keep rows 1 to 3 as the exhaustive public content.
   Conservative and consistent with "no T by talk".
c  fold rows 1 to 3 now, and open CENSUS-ERGODIC-BIJECTION as an H row with
   the falsifier already written, closing it at T only when a public
   self-contained proof of the unique-ergodicity step is authored.
```

This candidate recommends (b) for the first fold and (c) only if the owner
wants the count itself queued as live work. It does not recommend (a). The
count is reported here at candidate-T because the candidate lane permits a
provisional label; the public line has no obligation to inherit it.
