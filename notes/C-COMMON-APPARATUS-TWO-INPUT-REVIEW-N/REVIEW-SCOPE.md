## Frozen fingerprints and serialization

The case order is lexicographic `(n,k,m,l)` over `{0,1} x range(5) x
{0,1} x range(5)`. Every serialized state has all 56 labelled slots in
canonical four-integer j coordinates. Compact JSON uses ASCII, separators
comma and colon, no added whitespace, and no final newline.

- Endpoint payload: `[[[n,k,m,l],state],...]`, one final state per case.
- Checkpoint payload: `[[[n,k,m,l],kind,stage,step,read_index,state],...]`.
  kind is R, S or LOAD. Stage is zero or one; step is 0..9. R read_index
  is zero or one, and S uses -1. LOAD uses stage=step=read_index=-1.
  Per case, append R0,R1,S for each of ten first-stage steps, LOAD, then
  R0,R1,S for each of ten second-stage steps. There are 6100 such states.
- Full mixed-word bytes: ASCII `kind,i,j\n`, where kind is C or SWAP,
  for every chronological forward operation, including the final newline.
- R and S edge bytes: ASCII `i,j\n` per chronological zero-based contact,
  including the final newline, before the stage-B embedding.

operations, R_edges and S_edges. It is post-freeze comparison material and
is never used to generate expected states or read target output before the
