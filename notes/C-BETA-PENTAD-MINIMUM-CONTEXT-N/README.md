# Exact minimum of the external time context

**NON-CANONICAL. L1 mathematical proposal. Proof-only successor to the
completed P-BETA-PENTAD-NATIVE-EXTENSION-1 probe.**

The prescribed first-entrance lift needs exactly **five** externally supplied
time-context values to evaluate its checkpoint component on every fiber. The
same five classes are necessary for the single prescribed operation T, for
SO(B,F5), and for GL(3,F5). This sharpens the predecessor's upper bound of
24 length-nine driver factors for that same evaluation contract.

The [self-contained proof](PROOF.md) defines the contract, native fiber maps,
first-entrance chart and decoder. It gives an algebraic upper bound for every
linear C and an explicit lower bound using T on three common checkpoints.
No enumeration of a few selected matrices substitutes for the universal proof.

| Quantity and exact scope | Result |
| --- | ---: |
| Values of one context depending only on time, shared by all checkpoints and operations | 5 |
| Fixed consecutive forward driver window, with no additional time or parity input | 4 bits |
| Common checkpoints needed to distinguish all five actions | 3 |
| Context values when restricted to the active union z in {1,4} | 1 |
| Uniform first-entry time into that union, inherited from TM-SHEET-SYNCHRONIZING-GRAPH | 9 steps |

The 24 length-nine factors split into classes of sizes 6,4,6,6,2. Three bits
do not suffice: times 3 and 10 have the same prefix 010 but require different
corrections. Five labels are not an autonomous clock: kappa(0)=kappa(10),
whereas kappa(1) differs from kappa(11). The unchanged counter n is passed
through separately; it is not an additional input to the checkpoint decoder.
