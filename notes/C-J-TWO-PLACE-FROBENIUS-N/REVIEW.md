# Internal opposition and limits of verification

NON-CANONICAL. All new scientific conclusions remain candidate-D.

## Team and method

The working team consisted of root synthesis, one Astra algebra
development agent, a separate Astra opponent, and a Sol native-source
and decoder reviewer. Tasks ran concurrently. The opponent was asked
to seek counterexamples and distinguish the proposed arithmetic
observables from the actual native state.

All proofs were available within the same session. This is internal
adversarial review, not external independent review, blind confirmation,
or an architecture gate.

No new scientific program, verifier, exhaustive search or numerical
calculation was executed. Source reads, text edits, hashes, Git metadata
and repository integrity checks are not claimed as scientific evidence
for the new theorems.

## Corrections and safeguards

An intermediate general cubic expansion relayed during discussion had
the factor \(n+1\) mistyped in one term. Opposition and root corrected
it before the proof draft. The specialized coefficient and the reader
theorem were unaffected. PROOF.md includes the full corrected expansion.

The first finite-memory explanation proved the case where the four-phase
value was a terminal output. Opposition identified that feeding it into
memory requires an additional argument. DECODER.md now gives the explicit
four-letter prefix-product recurrence, covering that stronger declared
input class.

The phrase "two bits" is used only for the two vanishing flags.
The full reduced residual has ten possible values on unit classes.
Neither it nor the thicker sixty-class reading is identified with
the complete carry history.

The universal identity \(x^N=x\) is distinguished from the correctly
twisted prime law \(x^N=\sigma_N(x)\). The composite witness satisfies
both; nonsplit primes need not satisfy the first.

The norm argument does not discard the \(\sqrt5\) factor as a unit.
The factor contributes norm twenty-five and is only invertible modulo
the coprime indices used in the divisibility equivalence.

Several further paper observations about minimum conductors and shortest
history windows were deliberately omitted. The delivered claims do not
depend on them.

## Unresolved work

The bundle does not construct a native physical carrier for growing
precision or unbounded history. It does not prove the unit-index inert
obstruction for one separately fixed initial checkpoint. It supplies no
complete primality criterion, complexity advantage, RH estimate or
cross-layer gate.

Any future finite audit must receive its own prospective public pin,
exact verifier and declared falsifiers before execution. This paper
bundle must not be relabeled as having already satisfied that procedure.
