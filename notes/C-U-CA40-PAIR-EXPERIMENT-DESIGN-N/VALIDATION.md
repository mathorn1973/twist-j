## Cross-review repairs

The completed design incorporates these substantive corrections:

- Computational populations alone cannot distinguish G's phase or sign;
  phase-sensitive local measurements replace a circular inverse-G test.
- Initial fluorescence cannot distinguish both S levels. The explicit
  pre-readout auxiliary exchange prevents the ideal classifier from calling
  other-S leakage a correct code-0 result.
- Motion is probed before any fluorescence, pumping or recooling that could
  erase it. The probe ion is frozen per mode from ions 4/5 because a central
  ion may have zero coupling to a normal mode.
- Joint spectator return is required in the fully coherent pair-output C
  rows as well as basis and Ramsey rows; this uses existing trials.
- One protected waveform/correction file per sign/arm is independent of the
  prepared input labels and measurement row. Physical corrections cannot be
  replaced silently with fitted measurement phases.
- Classical confusion matrices alone do not bound coherent or correlated
  readout errors. The entanglement witness additionally needs a common-state
  or justified common averaged-state model across analysis choices.
- Bounded martingale concentration is not a stationarity proof or an
  anytime-valid partial-sample interval. Early statistical failure uses only
  completed predeclared samples; unresolved intervals remain INCONCLUSIVE.
- Additional signed-product correlations are exploratory diagnostics outside
  the enumerated primary confidence family. Quantum-source and arbitrary-
  reference guarantees are not inferred from this fixed spectator state.
