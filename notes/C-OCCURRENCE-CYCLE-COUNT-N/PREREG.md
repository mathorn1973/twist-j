## 2. Objects needed before a cycle count is scientifically defined

A fully admitted object would comprise a finite actual carrier X with
literal equality, a total autonomous permutation T:X->X, preparation
domains S_s within X fixed independently of the target trace weights,
and a total event transducer. A proved finite autonomous factor is also
eligible only if its projection intertwines the complete transition and
preserves preparation membership and the entire required event history.
An infinite actual carrier needs its own theorem and is outside this
finite-cycle test. A change of chart or omission of a clock is not such a
factor proof.

The event transducer must mark the end of a genuinely completed two-round
trial and retain its ordered LOW/HIGH word, contexts, invocation and
required interface state. A WRITE predicate, archive occupancy, reading
one old symbol again, or traversing the inverse tail is not a new trial.
Invalid input, failed writes, absent completion and capacity exhaustion
remain explicit; none is discarded as an inconvenient history. Every cycle
reachable from any admitted start must contain completed trial events.
Source renewal, if used to produce recurrent trials, must be part of the
already supplied complete autonomous resource account. No new machine or
unaccounted reset may be introduced to make this test runnable.

"All starts" means every x in the independently defined S_s for a fixed
preparation s, not the same unlabeled set for opposite phases. All
variables and correlations that influence continuation belong to X.
Following first HIGH, the actual remaining state continues under the same
T; it is not selected anew from the reference poststate. If an ensemble
description is used, the allowed conditional class is the image of the
initial class conditioned on the actual prefix, not a newly chosen class.

For a finite event alphabet A and reachable cycle C, let n_C(h) be the
number of genuine trial completions with full label h and m_C=sum_h n_C(h).
The finite criterion is m_C>0 and n_C(h)/m_C=q_s,Pi(h) for every admitted
cycle and h. For unbounded or continuous retained interface values, a
finite complete event alphabet or an independently adequate equivalence
must first be justified; the two-bit word alone is not automatically
complete. The frozen criterion concerns time frequencies of successive
completed trials. It does not imply the probability law of the first
two outputs from an unspecified initial law. Any such identification is
an additional hypothesis, not an output of the cycle theorem.

No microscopic probability measure is selected here. Uniform state
counting, if later used for a finite ensemble, is an explicit added
premise. For a map with five preimages per output, uniform input pushes
forward to uniform output; a point input still pushes forward to a point.
Five-to-one incidence does not create a preferred measure from arbitrary
input. Equally, reversible evolution can copy an existing symbol into a
ready record and does not imply a general impossibility of actual records.
