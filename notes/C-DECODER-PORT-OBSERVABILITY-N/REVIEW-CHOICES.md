## 3. What a genuinely composable physical bridge must supply

Let F_c be the specified complete model transition and Phi_c the actual
physical transition in the same independently identified context. A sufficient
condition is a relation R between complete model and physical states such that
preparation establishes R, every transition preserves R, and the corresponding
observations agree. Induction then transfers the entire ordered record, not
just one scalar at one step. With uncertainties, use an independently bounded
error relation propagated through every step. The earlier realization notes
already require full state, memory and error accounting; this is a concise
statement of the composition condition, not a new physical result.

Why a weaker diagram is unsafe: take visible/hidden bits (x,h), encode
x as (x,0), decode by x, model F(x)=x, and reversible physical update
Phi(x,h)=(x XOR h,h XOR 1). Every one-step prepared visible value matches F,
but the second visible value is 1-x. This is an elementary analytical control,
not a new formal execution or a counterexample to a fully specified physical
certificate. Invisible memory must not be discarded from a multi-step premise.

The source-specific port theorem supplies one exact observation map on the
model side. It does not establish R for a physical apparatus.
