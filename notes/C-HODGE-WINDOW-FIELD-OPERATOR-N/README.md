PUBLIC NON-CANONICAL. Owner: #1237.
Author: A. M. Thorn <thorn@twistj.com>.

This note puts a scalar mixed-difference field operator on the actual
windowed Hodge events. It proves an exact inherited Lorentz principal tensor,
a quantitative O(n^-2) event-field limit and a local mode map from the
registered D3 photon characteristic.

It also preserves three negatives: diagonal six-direction weights cannot do
the job, the literal unit stencil is not total, and the chosen total rounding
stencil is not exactly C5/J equivariant at finite scale.

No finite-n Cauchy theorem, physical photon or Canon promotion.
