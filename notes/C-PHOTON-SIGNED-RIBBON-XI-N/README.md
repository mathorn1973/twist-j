# Uniform signed-slice Xi bound for high-contact ribbon cycles

**PUBLIC, NON-CANONICAL.**

The sign-sensitive class #1179 enlarged the controlled simple-cycle sector but
still excluded sufficiently dense reinforcing contacts. This note controls an
explicit all-distance family deep inside that complement.

The mechanism is different: a dense ribbon has many reinforcing contacts but
very little independent geometric entropy. It is generated by one path, not by
two unrelated current strands.

## 1. Contact-simple ribbon

Choose an oriented coordinate `b` and a simple nonbacktracking path

`
P=(v_0,...,v_D),  D>=2,
`

using no edge parallel to `b`. Require that `P` and `P+e_b` are
vertex-disjoint.

Follow `P` forward, cross by `e_b`, follow `P+e_b` backward and close by
the opposite connector.

Restrict to ribbons whose only opposite-edge plaquette contacts are the
`D` corresponding pairs between one path edge and its translate.

If `c_P` is the number of turns of the base path, direct geometry gives

`
m=2D+2,
c=2c_P+4,
O_+=D,
O_-=0.                                                  (1)
`

Each corresponding pair is reinforcing because the two translated strands
are traversed in opposite directions.

## 2. Source price and geometric entropy

At `h=log3`,

`
a=15625/177147,
r=41/25.
`

The existing current source estimate gives

`
P(E_gamma union E_-gamma)
 <= 2 a^(2D+2) r^(D+2c_P+4).                           (2)
`

Fix the ribbon displacement, start and first direction. Since the base path
uses a three-dimensional coordinate hyperplane, every further
nonbacktracking step has one straight continuation and at most four turns.

A turn of `P` appears once on each strand, hence costs `r^2`. Dropping all
self-avoidance and contact restrictions only increases the sum. The exact
one-step majorant is therefore

`
1+4r^2.
`

Define

`
boxed:
q_rib=a^2 r(1+4r^2)
     =4707953125/31381059609
     <1.                                                (3)
`

This is the decisive inequality. Dense reinforcing contacts are harmless in
this family because each added contact arrives together with two new current
edges while only one base-path choice is made.

For a fixed start, displacement and first direction the length-`D` event
sum is

`
<=2 a^4 r^5 q_rib^(D-1).                               (4)
`

## 3. Volume-uniform signed moment

There are at most

`
V * 8 * 6
`

oriented ribbon descriptions from a periodic volume `V`: a start vertex,
an oriented displacement coordinate and a first path direction. Duplicates
only improve an upper bound.

The signed-cycle lemma from #1176 gives

`
ell(gamma)^2 <= m^4/256=(2D+2)^4/256.
`

Therefore

`
Xi_rib(L)
 <=6 a^4 r^5
   sum_(D>=2)(D+1)^4 q_rib^(D-1).                       (5)
`

The factor `V` has cancelled the normalization in `Xi_L`.

For `0<q<1`,

`
sum_(D>=2)(D+1)^4 q^(D-1)
 =
(16+q+11q^2-5q^3+q^4)/(1-q)^5 -16.
`

Hence for every admitted finite volume

`
boxed:
Xi_rib(L) <= C_rib
`

with exact

`
C_rib =
24970997955647887886612946733927769359355575308574483756351470947265625
/

`

Unlike the deliberately huge general cycle constant in #1176, this one is
already small at the level of the exact rational itself. No decimal is needed
for the theorem.

## 4. This genuinely enters the previous complement

For a ribbon,

`
O_+/m=D/(2D+2),
O_-=0.
`

The #1179 signed-contact class requires

`
r^D <= tau^(2D+2),
tau=73/70.
`

The exact audit finds that this already fails at `D=2`. Thus the ribbon
bound controls configurations which #1179 did not.

As `D` grows, `O_+/m` tends to one half, far above the old `1/12`
reinforcing-contact threshold.

## 5. Scientific boundary

The result is not a theorem about every high-contact simple cycle. It uses the
one-path ribbon encoding and the prohibition of extra self-contacts.

What it establishes is the relevant mechanism:

`
high contact density + paired-strand geometry
does not imply large Xi activity.
`

The remaining simple-cycle problem is therefore not merely high
`O_+`. It is high reinforcing contact density **without a low-entropy ribbon
description**.

Still open:

- ribbons with additional self contacts;
- general high-contact simple cycles;
- non-simple current networks;
- multi-cycle paired components;
- full `Xi_L`, `Xi_L^(2)`, P1 and massless phase.
