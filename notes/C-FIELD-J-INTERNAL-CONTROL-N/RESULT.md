```text

F^-1 = sum_s |s><s+1| tensor J_s*.
```

This is a fixed local rule on the declared port graph. The head carries all

the actually addressed memories. The graph has maximum degree four and a
conservative radius-two gate-plus-motion scope. This is not an embedding

