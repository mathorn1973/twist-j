# Review

PUBLIC NON-CANONICAL. Proof-aware same-session review, not independent-agent
confirmation. Author: A. M. Thorn <thorn@twistj.com>.

The following distinct issues were checked.

1. Hexagonal layers: the explicit inverse, not count matching, establishes
   the bijection. The layer tag fixes the diagonal projection ambiguity.
   Signing and the infinite cover remain choices, and the original metric
   is not asserted to be preserved.
2. Prefix connectivity: lowering a boundary coordinate reaches an earlier
   boundary-count group or the completed inner cube. Reversing only the lex
   order cannot break this argument. Edges are attached once at their later
   endpoint; old adjacency lists are not silently rewritten.
3. Metric: the positive spatial projection is used. The Lorentz interval
   alone was not called a distance. The bound on rounding relative to minimum
   lattice separation gives the all-pairs 5/9,13/9 comparison. The proved
   dimension notion is large-scale metric-ball growth, not Hausdorff or
   physical dimension.
4. Field: every recurrence predecessor is in an earlier shell or at smaller
   m in the same shell. Equality with the infinite-grid solution is an
   induction, not the assumption that a finite reflecting boundary has no
   effect. Local-aperture energy and global energy are kept distinct.
5. Budgets: spatial points and spacetime/field points have different cubic
   and quartic counts. All points, including zero field values, are counted.
   Unbounded bit size and symbolic compression are not hidden behind the
   atomic-record count. The executable supplies c=1; batching is a stated
   proof-level wrapper, not an untested alternate simulator claim.
6. Selection: the metric-control counterexamples belong to the broad prefix
   class, not to the more constrained class that already fixes the Hodge
   metric. Native bits change serialization, not the limiting target.
7. Time: generation index N and event time m are different. The construction
   does not inherit m=N from the previous single-point bridge. Physical
   native memory and clock calibration have not been proved.

The two successful architectures replayed the same unchanged prospective
code. The comparison with a sparse scalar implementation is a separate
formulation within this session, not a blind second author's proof.
