## Challenges and dispositions

| Challenge | Disposition |
|---|---|
| Does uniqueness by itself make the period nonzero? | No. It makes the fixed global functional a scalar times a nonzero reference map. The actual normalized W constructs that reference map; the global scalar may be zero. |
| Is the real Bessel subgroup the one in the theorem? | The source has U(k+r,r+1), a negative anisotropic line and U(k). JSZ Section 2 matches this pair, including its generic character. For r=0 the restriction is U(k,1) to U(k). |
| Is evaluation legitimate on L2 classes? | All evaluations use canonical smooth automorphic representatives or smooth relative sections. Local Sobolev estimates give continuity, and full-support Haar measure identifies the smooth relative representative with continuous W everywhere. |
| Is a bounded row assumption silently imposed on the entire HH? | Corrected. The square-integrable absolute seed periodization from round 8 and Cauchy-Schwarz permit absolute unfolding for every actual row. Applying the positive supported-function fold to real/imaginary positive and negative parts gives the same constant without global boundedness. |
| Does PerLaw supply a nonzero normalization? | Its bare interface does not. The genuine fold theorem explicitly supplies a strictly positive real constant; the actual constructor uses it. |
| Could conjugation reverse the scalar? | Checked with the first inner-product slot antilinear. The period is conjugate-linear in the row. Its Riesz map is linear, and Q=(b/c)P, while Q*=conj(b/c)P*. |
| Is the convolution rank one in the relative representation? | Wording corrected. It is rank one on Sigma. In a representation with multiplicity the needed statement is P R(g)P=<w,Sigma(g)w>P. This suffices for the cyclic isometry. |
| Does product multiplicity one need an unstated irreducibility result? | The local continuous bilinear statement is applied successively on elementary tensor vectors; normalization and density give the product statement. The actual product compact type is supplied by the source. |
| Can continuous nonzero functions have disjoint supports? | Yes. The proof therefore establishes real analyticity using the infinitesimal and compact Casimir eigen-equations. Connected U(p,q) and finitely many words then give one common dense open nonzero set. |
| Must w be a highest-weight vector? | No. It is smooth and lies in the given compact isotypic type of an admissible discrete series, so the compact Casimir acts by one scalar. This is exactly what the elliptic argument needs. |
| Is the common point uniform in the parameter family? | No. It is one point for all words, rows and columns of a fixed finite instance. Neither a uniform lower scalar bound nor an effective selection follows. |
| Are the common point and common smooth vector the same statement? | No. The latter uses rational Witt transport and pairwise inequivalent compact types. Its vector need not lie in the original compact cut or factor as a tensor, and no uniform norm estimate is obtained. |
| Could different words have equivalent compact types after transport? | data8 separates their parameters at every real place; the common rho shift and inner unitary frame transport preserve inequivalence. Coincident finite level primes do not affect this argument. |
| Does the real annihilator calculation use the compact center incorrectly? | Apply Yamashita to SU(p,q), whose center is finite. The scalar compact center of U(p,q) contributes zero in the associated variety. The rank bound and explicit chain compute the exact hook. |
| Does the orbit obstruction show a global coefficient exists? | It only excludes larger hooks. A cuspidal target coefficient requires first occurrence exactly r_S and the prescribed rational orbit. Discreteness alone does not supply the cuspidality hypothesis for Jiang-Zhang's tower proposition. |
| Do identical real signs determine the rational orbit? | No. The residual space contains a rational hyperbolic plane and represents distinct norm classes with the same real signs. The long-chain Hermitian line is a rational conjugacy invariant. No automorphic occurrence on either class is inferred. |
| Can one successful automorphic copy eliminate an isotypic kernel? | Only at multiplicity one. At higher multiplicity the closed right-invariant kernel is K_pi tensor H_pi, where K_pi is a subspace of the multiplicity space. The formula counts its dimension rather than basis-dependent copies. |
| What happens at r_S=0? | The unipotent Fourier transform is the identity on automorphic functions, so its global kernel is zero. Selected compact restrictions and column tests may still lose rank. |
