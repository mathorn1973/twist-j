# Next acceptance boundary: physical work and a retained event

NON-CANONICAL / OPEN proposal. No physical realization or empirical result.
The mathematical theorem and its executable audit remain L1. This file
neither registers a cross-layer gate nor starts a laboratory protocol.

## What this milestone closes

The specified mathematical machine joins one prepared source, an actual
stored resource path, a paid receiving reaction, a stateful event writer
and one fixed local reader. Its full state and inverse are explicit. The
same-energy offimage source and every single cut prevent the prepared
record. The old receiving reaction can reverse while its recorded event
remains distinguishable. This is a complete conditional construction of
a reversible work-to-record unit in the declared discrete model.

There are three distinct acceptance questions:

| Question | Present disposition |
| --- | --- |
| Does the exact declared machine perform these operations with a closed model account? | Conditional proof; finite code audit is a separate recorded check. |
| Can a specified physical device implement the operation and transfer measured work with its whole apparatus accounted for? | Open; no device or laboratory data has been supplied. |
| Does this law predict an independently measured physical system beyond data used to select or calibrate it? | Open; no empirical model-selection test has been supplied. |

Successfully programming the reaction predicate into a device would address
implementation. It would not by itself show that nature independently selects
that predicate, the channel law, the reader, or the fivefold pointer.

receiver and pointer. The primary quantity is transferred physical work,

Do not infer transferred work solely from a variable named resource in a
computer program. A software run already belongs to the mathematical audit.

Before any apparatus construction or measurements used as evidence, supply

   Give an encoding Enc from the frozen model domain into these physical states,

5. Numerical tolerances, instruments, sample counts, horizon, uncertainty

## Concrete success and failure conditions

For the admitted N=3 preparation, physical delivery, paid local reaction and
first pointer change must have the declared order; the pointer must remain
distinguishable over the eight corresponding boundaries 3..10 while the
original receiving state returns at boundary 4. Both cut controls and the
specified equal-energy offimage input must remain blank over the frozen
measurement horizon. Finite laboratory data cannot prove an all-time null.

Measure the transferred contribution corresponding to two model units
against source loss and receiver gain, using the declared physical energy
dictionary and accounting for apparatus exchanges. An independently powered
receiver that merely reacts to a logical notification would not satisfy this
work-transfer contract. The source and offimage preparation must match the
predeclared physical energy criterion, rather than only equal software labels.

Failure of any frozen balance, input/readout correspondence, discrimination,
control or retention threshold rejects that realization at that scope. It
does not refute the already exact algebraic theorem or all possible devices.
Conversely a successful engineered realization gives feasibility evidence
for that device, not a universal natural law. Empirical selection requires
independent physical predictions on the frozen holdout class.

## The meaning of the pointer's unit energy

E_p(p)=1 is an explicit constant model assignment to five distinct states.
It makes the full model account 42 rather than 41, but its change during a
write is zero. A constant offset alone cannot establish an experimentally
required preparation cost or a paid work increment. Those need the specified
physical carrier and reference states. Neither zero change in E_p nor exact
logical invertibility establishes zero dissipation or zero controller cost
for a real implementation. This is an open part of the physical dictionary.
The distinction between logical reversibility and the thermodynamics of
specific implementations is discussed in Bennett's
[1982 review](https://research.ibm.com/publications/the-thermodynamics-of-computation-a-review);
no measured dissipation bound for this proposed device is inferred from it.

The extra carrier, its five distinguishable configurations and the enlarged
event-controlled gate are therefore counted as architectural choices even
though the model pointer energy is degenerate. No automatic identification
of model integers with joules, of steps with physical clocks, or of contacts
with propagation at the speed of light is made.
