**E-INV (written argument, four-arrow scope).** At a fixed base and under
the declared coordinate and word transports, each of the four currently
studied admitted arrows preserves
`Phi(P)`, the set of futures `F_x(v) = w(delta_v x)` of the Sigma*-reachable
states, up to its transport:

- relabeling transports the futures;
- restriction keeps `S_reach` and its futures;
- the Nerode quotient under its precondition has `F_[x] = F_x`;
- permutation transports the V-tuples.

Hence `approx_red` generated by these four arrows implies equal `Phi`.
This invariant is not asserted for an expanded arrow class.

Consequences, depending on what "complete" is read against:

```text
against equal canonical start streams (RS)     incomplete already at rank one
against equal start V-futures (RV)             incomplete on noncommuting tuples
RV on the commuting class                      complete (E-POS; census 5402 pairs, 0 splits)
```

- **RS, witness W-S.** A rank-one tuple, under MSD and LSD with E0 and Z0,
  has equal canonical streams (exact product automaton, and `n < 4096`) but
  different `Phi`. States reachable only through noncanonical words (leading
  zeros in MSD, trailing zeros in LSD) carry futures that the stream never
  shows. No one of the four arrows removes them: restriction keeps `S_reach`, and the
  Nerode quotient uses all V-tuples of words.
- **RV, witness W-V.** A noncommuting tuple with `q = 2`, `a = 2`, `|S| = 3`
  has equal start V-futures but different `Phi`. `S_reach` contains a state
  reachable only against the coordinate order.
- **E-POS (written argument).** On commuting tuples every Sigma*-reachable
  state is V-reachable, and the Nerode precondition holds automatically. The
  reach-plus-Nerode normal form is then determined by the set of start
  V-futures, so `~V` implies `approx_red` through
  `P -> reach -> quotient ~= quotient' <- reach' <- P'`.

Census, `q = 2`, `a = 2`, `|S| = 2`, `A0 = {0}`, binary `w`, 1024 tuples:

## Consequence for the current obligation

For these four arrows, W-S obstructs completeness under RS, and W-V
obstructs completeness under RV on the unrestricted noncommuting class.
Neither witness establishes an obstruction for every possible expanded
calculus. Incompleteness by itself is not among the negative-closure clauses
of METRO-REDUCTION-CALCULUS. Under either obstructed comparison contract,
these results therefore leave the parent O and STOP: further progress needs
an explicit public change of scope or a separately specified successor,
rather than reinterpreting incompleteness as a registered negative closure.

change. This note and its unchanged historical preregistration provide no
