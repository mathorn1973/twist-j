The key correction is sharper than "J is reversible, U is irreversible":

```text
J on the integer lattice:    bijective, but not additively conjugate to J^-1
unmarked unit quotient:     reversible by Galois reflection
full U on N_0 x F_5^6:       noninjective and not onto
origin-zero tail, n >= 3:   injective, slice-to-slice bijective, not onto
two-sided stable TM hull:   bijective with an explicit involutive reversor
physical decoder:          no physical time-reversal/locality selection here
```

The negative unit result is a restriction on a symmetry-invariant selector,
not a proof that all algebraic invariants fail to distinguish J from J^-1.
The trace is an explicit counterexample to that stronger assertion.

The native no-finite-autonomous-realization theorem concerns exact
aperiodicity. It does not prohibit direct computation of a specified late
checkpoint: U-NATIVE-CHART-AND-QDD-READBACK [T] already supplies that jump.

Selected geometric output constructions also already exist. In particular
the generative-geometry note supplies a chosen graph, metric and scalar
stencil, with extra inputs and a represented field clock distinct from the
native serialization clock. The unresolved task is a justified native
spatial realization, not merely writing a local stencil on an added graph.
