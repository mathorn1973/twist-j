## Claims rejected from the motivating argument

The following assertions are not retained as candidate theorems:

1. Every orientation requires an externally selected complex embedding.
   Marking J already specifies one algebraically.
2. No algebraic invariant distinguishes J and J^-1. Trace does.
3. Full native checkpoint evolution cannot be jumped over. The existing
   exact chart gives logarithmically many arithmetic operations.
4. The native one-sided process has the nonempty stable natural extension
   of the auxiliary two-sided hull. Native Nat(U) is empty.
5. Checkpoint merging proves thermodynamic dissipation or quantum
   nonunitarity. Neither follows without the complete physical contract.
6. Abelian piston action rules out every external geometry. It rules out
   the stated nontrivial commutator action only under its precise premises.

These are corrections to the supplied argument, not fired public probe
falsifiers, and not changes to historical results.
