## What the counter and selector can carry

The native trace and selected index become independent of the initial
checkpoint after three steps. For any bijection `L` on any target set,

```text
r_n(i_n(x0))=L^n v(x0) for every n and every origin-zero head
    implies v is constant.
```

The same statement holds with the current trace. It allows arbitrary
nonlinear readers and the full unbounded counter. Complete selector history
retains exactly five initial trace classes. If its target amplitude also
factors through `Q`, that amplitude must again be constant.

The static selector alphabet does supply the usual augmentation-lattice
representation of `J`: `(I+C^2)|A4`, followed by its exterior square.
The actual selector performs `C^(2t)e_z`, not `(I+C^2)e_z`. Adding both
alternatives changes the operation. This construction therefore supplies
neither the native Hodge transition nor its state-dependent amplitude.

The full checkpoint does retain Q. Assigning arbitrary target values
`G(Q)` gives the allowed separable reads `L^n G(Q(x))`. A chosen set of
thirteen values can span a rational six-space, but cannot cover it. The
choice of G, the characteristic-zero lift and the inserted L remain
unselected. This is the precise remaining native-amplitude problem.
