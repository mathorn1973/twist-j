The task is a single local positive static Hamiltonian for two source
attempts, two retained outputs and a final reset of the working hardware
at its original physical sites. A counted thermal controller must run
the complete sequence. The first record must remain available during
the first reset and the second attempt. A common joint channel, rather
than a product of marginal success bounds, determines the output.

[CONTRACT.md](CONTRACT.md) fixes support, geometry, coupling cap, errors,
resources and failure conditions before the complete larger construction.
This first pin is an analytical design contract, not blind discovery or
a scientific execution. No scientific program or matrix expansion is
authorized by this note. Proof and resource files follow separately.

The intended proof route uses a local product approximation of the
frozen core endpoint, sitewise conserving export/reset contacts, a
three-dimensional transport layout and a thermally launched history
clock with fixed interaction strength. Every transport copy and changed
state belongs to the resource count. Permanent closed storage and
perturbation robustness are not claimed by the present contract.
