## Limits that matter

The raw c offset is not a third hidden state digit. Correlated errors
created by differencing must not be assigned an independent-symbol noise
guarantee. An error-correcting code exists here as a mathematical
construction; no autonomous native repair law has been demonstrated.

The native writer's correlated preparation is supplied, its declared
input family has 25 elements, and its raw receiver is literal at cut3. The original
clock-assisted reader retains the data thereafter. The stronger reference
reader removes the counter from the observation interface by reading
four current pistons and the six-coordinate sum. The counter remains
in the native evolution. Neither observation is a physical detector or
an internally implemented decoder circuit. No arbitrary-625-input native
writer, autonomous repair or renewal protocol is asserted.

KERNEL-Z6-SYNCHRONIZATION and U-NATIVE-INVARIANT-AND-NOWRITE already
provide synchronization and invariant retention. Their application here
does not add a new canonical mechanism. U-NATIVE-SOURCE-RECEIVER-RECORD
has a distinct one-digit construction with a common complete receiver,
payload-independent references and a designated forever-absent input;
E does not supply those same resources. The new split-capacity proof
concerns current values and observed histories, and supplies no native
archive for its two samples.
