Use the original U(n,x)=(n+1,g_j(x)), j=sum(x)+2 theta_n mod5,
theta_n=popcount(n) mod2, with the five unchanged canonical generators.

1. One native tick 0 -> 1, classical carrier untouched.

ends at 3. No P-sidecar window is attached or silently shifted away.
