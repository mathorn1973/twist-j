## Supplied preparation object

The receiving descriptor names N, K, L=613, m=K+1, the complete inherited
C carrier, every initial source/reference and pointer correlation, the
new internal mode graph, all n_i, and the exact classical pulse script.
The source/code preparation, initial zero archive flags and ready B
geometry remain boundary inputs. Even support of each pointer and fresh
independent basis-zero baths specify the positive domain. This is a
mathematical promise about a preparation, not an operational test on an
unknown state.

The exact prepared object is the full output

```text
rho_out = W [rho_in tensor |0^B><0^B|] W^*,
B = L sum_i n_i.
```

Every collision reflection, pointer address and distinct bath address is
fixed by the descriptor. All bath ket/bra cross terms, old pointer data,
and source/reference correlations remain in rho_out. The inverse is the
reversed product of the same reflections. No reduced pointer density is
substituted for the complete output.

Let Q denote all m pointer coordinates and Z' everything else, including
all baths. Write R=P_E^(tensor m), where P_E=|E><E|, and

```text
delta = min(1, sum_i (1-4/L^3)^(n_i) (1-F_(i,0))),
epsilon = min(1, sqrt(delta)+delta/2).
```

The exported approximation is

```text
(1/2)||rho_out - R tensor rho_(Z',out)||_1 <= epsilon.
```

The comparison retains the actual remaining marginal. It does not posit a
fresh environment independent of the source. The original source/reference
marginal is unchanged. If the initial F_(i,0) are not known, the declared
worst-domain bound uses F_(i,0)>=0; it does not measure them or select
successful preparations. Equal basis blanks have F_(i,0)=1/L.

For a chosen error target the finite script is selected from the proved
bound before loading. It is not stopped by inspecting a desired record or
postselecting a hidden readiness outcome. No finite exact E guarantee is
exported from the dyadic basis-blank slice.

and does not clear its flag. A dirty bath, odd pointer or exhausted supply

silently admitted to the positive preparation theorem. A future controller
must implement its own handling of these inputs.

## What the approximate interface transports

Apply the same admitted finite C instrument and causal control descriptor
to the actual and comparison inputs. Retain every branch and bounded
stopping leaf, and keep loading baths as spectators. The resulting complete
CPTP map contracts the joint trace-distance error to at most epsilon.
This holds for the whole once-loaded bank; there is no automatic extra
error charge per passive read or per trial. Additional approximate
interventions would need their own composed error bounds.

Consequently, formal trace distributions have total-variation error at
most epsilon, and each prefix trace differs by at most epsilon. Normalizing
a rare branch may amplify error; the frozen specification gives its bound
only when both branch traces are positive. An ideal zero-weight branch can
acquire nonzero trace. The interface supplies neither exact zero support
nor a uniform conditional-state approximation on arbitrarily rare prefixes.

These statements compare operators under specified quantum maps. They do
not give a measure on actual initial states, select one branch, or establish
observed frequencies. Allowing bath access requires a newly specified joint
protocol and comparison, rather than an assumed source-marginal channel.

## Additional fields required of the actual-record successor

A concrete successor must declare a complete actual-state space and its
relation to the complex representation. It must supply initial conditions,
actual transitions and a total finite record-prefix map, including invalid
preparation, no completed event and exhausted capacity. A density operator,
parity projector, dephased block or collection of bath amplitudes does not
by itself define which single result occurred.

The record controller must account for context-command loading and storage,
clock state, trial invocation, actual round timing, unused-cell selection,
append, epoch advancement, read completion and capacity handling. Each
operation needs an input predicate, complete updated registers, and behavior
on invalid states. Supplied boundary controls may remain in an explicitly
limited effective model, but they cannot be called an autonomous realization.

Three predicates must remain distinct: the funded B WRITE, the value of a
parity record, and an archive flag toggled by append. WRITE occurs on every
supported component; a flag can be toggled with no prior WRITE. A provenance
claim must be proved on the actual supported protocol and state, rather
than inferred from either flag or interaction timing alone.

Only after these fields are supplied can a realized-history proposal define
its own initial-state measure or frequency construction and compare its
prefix law with C's trace law. The right-hand comparison formula cannot
serve as the definition of the left-hand occurrence mechanism.

The receiving checks include equal populations with different coherence,
correlated inputs, wrong parity, phase mismatch, reused or exhausted baths,
unauthorized bath feedback, false flag provenance, source replacement and
rare/zero prefixes. None of these fields closes the three physical QDD
owners or introduces a second conditional writer.
