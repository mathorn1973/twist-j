1. No complete nonredundant beta digit set containing zero represents every

2. The balanced coefficient encoding admits the explicit scalable local
   reversible circuit family for J, its inverse and the two-register
   ramified transfer, with clean carries and declared reserve/boundaries.

   for an exact J macrostep; the displayed lower bound is linear in width.
4. In the frozen residue-only reader classes, a single ramified symbol
   needs phase divisible by four and a full mod-five packet needs phase
   divisible by twenty.
5. A selected finite program of these operations admits the explicit
   uniform autonomous one-head rule V_N, with bounded local forward and
   inverse rules on consistently marked intervals. Its program phase has
   fixed size independent of interval length.

realization. No physical encoding is selected by existence. Other redundant
codes are not excluded by the latency theorem, and the literal digit no-go
does not exclude terminal states or a different numeral system.

The supplied controller resolves scheduling only for the selected program
and marked one-head carrier. The next dynamical gate must justify the
instruction policy, boundary/ready preparation and capacity growth; a native
realization needs a separately justified interaction with the declared U.
A spatial interpretation needs its own graph-selection and layer gate.
These obligations remain NOT DERIVED in this note. The period of the head
is not asserted to be the period of the entire data state.

preregistration and accepted verifier committed before execution. No code or
