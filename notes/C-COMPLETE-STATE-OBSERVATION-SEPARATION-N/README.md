## Purpose

This note separates three objects that recent TWIST-J work now distinguishes
sharply:

1. the **complete internal state** carried by a declared mathematical or
   physical model;
2. a **contextual observation** or predictive read of that state;
3. the **geometry of physical events**, if such a geometry is eventually
   constructed.

The distinction is not cosmetic. Two public work lines now expose the same
logical boundary for different reasons.

- The merged Hodge observation-stability note shows that one fixed-direction
  four-coordinate predictive read need not determine another direction's read
  on the full real carrier, even though exact algebraic reconstruction can
  remain possible on a narrower rational or integral class.
- The retained-memory ion construction shows that two distinct inputs may
  require the same prescribed data output while reversibility forces their
  distinction to remain in another counted output. The exact 64-block
  construction stores that distinction in an occupied memory ion.

The synthesis here does **not** identify these two mechanisms. It extracts the
common factorization principle that both instantiate.

## Missing bridge

A future claim that one physical event geometry is read from the same complete
apparatus state must provide, at minimum:

1. the complete physical state carrier and its equality;
2. the admitted preparation domain;
3. the physical update/contact family and all counted output resources;
4. the context family and physically available read maps;
5. the event carrier, event equality and coordinate-overlap rules;
6. the rule relating internal-state evolution to event displacement or causal
   influence;
7. an accuracy topology or error metric that distinguishes exact algebraic
   coding from finite-precision stability;
8. explicit memory, controller, motion and work-source accounting;
9. named action-layer gates for every claimed lift beyond L1.
