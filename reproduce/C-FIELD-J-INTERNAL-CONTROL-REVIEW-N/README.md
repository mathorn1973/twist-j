# Independent internal-control audit

PUBLIC, NON-CANONICAL. Original implementation under Apache-2.0.
The exact independent domains, exposure boundary, falsifiers and run
envelope are frozen in
`notes/C-FIELD-J-INTERNAL-CONTROL-REVIEW-N/PREREG.md`; the independently
derived universal argument is in the sibling `PROOF.md`.

This is a standalone Python standard-library integer/Fraction audit.
It reads no runtime files, imports no predecessor or author scientific
implementation, performs no sampling, uses no floats and writes no files.
It tests actual instruction fetch, addressed swap tours, local processor
actions, cursor inverses, complete retained output columns and their
matrix units, bath isolation, inverse return and the formal-report
boundary. Reduced L=3 measurement programs are the labeled toy model;
the actual C audit uses L=613.

Only after the complete source is publicly pinned and read back:

```text
python3 -I reproduce/C-FIELD-J-INTERNAL-CONTROL-REVIEW-N/verify.py
```

The preregistered first-run envelope is 120 seconds in the deterministic
environment specified by PREREG. The coordinator captures stdout into
EXPECTED.txt and records custody/environment after that first run.
Neither expected output nor a passing run is asserted at source freeze.
No source edits or unreported reruns are allowed after the pin.

The original primitive catalogue is shared by the routed and direct
memory-target paths within this verifier. Thus their comparison isolates
fetch, routing and controller correctness, while the independent paper
proof and local inverse/energy audits cover the primitive formulae.
All-step and arbitrary-reference claims rest on the proof, not finite
rational sampling. Scientific execution and author-source release remain
coordinator-owned.
